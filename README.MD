# APD – Laborator Proiect de laborator pentru disciplina Achiziția și prelucrarea datelor. Nod de achiziție a temperaturii bazat pe Arduino Uno.
# AUTOR Turcu Rares Ioan 4LF342

Platforma: Arduino Uno R3 (ATmega328P)
## Parametri
* `SENSOR_PIN`: Intrarea analogica a senzorului (A0)
* `SAMPLE_PERIOD_MS`: Perioada de esantionare a datelor (1000 ms)
* `SERIAL_BAUD`: Viteza de transmisie pe portul serial (9600 baud)
* `LED_PIN`: Pin digital pentru LED-ul de stare (13)
* `BUTTON_PIN`: Buton pentru pornire/oprire achizitie (2)
